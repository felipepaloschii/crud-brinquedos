# CRUD Brinquedos

Sistema de gerenciamento de brinquedos desenvolvido em PHP e MySQL.

O sistema permite cadastrar, listar, editar e excluir brinquedos, utilizando Prepared Statements nas operações com o banco de dados.

# Como executar
Coloque a pasta do projeto em C:\xampp\htdocs. <br>

Inicie Apache e MySQL no XAMPP. <br>

Abra o phpMyAdmin. <br>

Crie o banco de dados brinquedos. <br>

Importe o arquivo db/crud_brinquedo.sql. <br>

Acesse no navegador:
http://localhost/crud-brinquedos/
